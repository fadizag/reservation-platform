# Reservation Platform UI/UX Design Specification

## Approved direction
- Premium Minimal
- Light-first
- Charcoal + Cream + quiet Terracotta
- Tajawal typography
- Soft cards, 12–16px radius, restrained shadows
- Hybrid navigation: mobile bottom navigation, larger-screen navigation
- Rounded line icon language
- Minimal map + smart information layer
- Charcoal primary CTA
- Muted semantic status colors with text/icon semantics
- Smart passenger home and current-trip-first driver home
- Hybrid reservation status card + timeline
- Hybrid booking summary over map on supported map-enabled screens
- Smart scheduling presentation
- Smart notifications
- Profile card + compact stats
- Hybrid reservation details
- Dialogs for sensitive actions
- Mobile-first, responsive, Arabic RTL
- Preserve all existing business logic and endpoints
